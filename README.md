The objective of this project is to automate the intake, approval, and fulfillment of software installation requests through ServiceNow’s Service Catalog and Workflow capabilities.

Key goals include:

Provide a standardized Service Catalog item for software installation requests.

Automate approval workflows based on requester’s role, department, or software type.

Assign tasks to the correct IT fulfillment team for installation.

Reduce manual coordination between users and IT.

Track requests in a centralized system for better visibility and SLA compliance.

Enhance end-user experience with faster and transparent software delivery.
